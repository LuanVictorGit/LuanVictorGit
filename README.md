<a id="sobre"></a>
## Sobre mim

Sou fundador da **Angatu Sistemas** e desenvolvedor full stack. Trabalho de ponta a ponta: converso com quem tem o problema, desenho a solução e escrevo o sistema — sem camada de atendimento no meio.

No dia a dia isso significa:

- Desenvolvimento full stack, do backend em Java/Javalin ao frontend que o cliente usa.
- Sistemas sob medida quando um programa pronto não resolve o problema.
- Produtos próprios, mantidos e evoluídos pela Angatu — não só projetos pontuais de cliente.
- Automação de processos manuais (planilha, caderno, grupo de WhatsApp) que travam a operação de uma empresa pequena.

*Angatu* vem do tupi *porã + katu*, "muito bonito" — a mesma raiz do nome de Porangatu, cidade onde a empresa nasceu.

<a id="filosofia"></a>
## Como eu penso desenvolvimento

Tecnologia não é o objetivo — resolver o problema é. A ferramenta é escolhida depois de entender a necessidade, nunca antes.

Na prática, isso guia algumas decisões:

- Entender o problema antes de abrir o editor. Um programa pronto que já resolve é melhor do que um sistema novo.
- Software sob medida quando a necessidade é específica o suficiente para justificar.
- Segurança e manutenção não são etapas opcionais — fazem parte do que é entregue, não do que fica para depois.
- Quem escreve o sistema é quem conversa com o cliente. Sem camada de atendimento no meio, o problema chega sem ruído.
